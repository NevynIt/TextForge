# Tables Examples

This folder contains bundled CSV/TSV fixtures for the `@textforge/tables` grid surface.

- `people.csv` is a normal comma-separated file with a header row.
- `inventory.tsv` is a normal tab-separated file with a header row.
- `headerless-sales.csv` is a CSV file with no header row.
- `malformed-quotes.csv` is an intentionally broken CSV fixture for failure-panel and diagnostic checks.

Use these files from `/.textforge/resources/docs/examples/tables` during the manual table-surface checks.

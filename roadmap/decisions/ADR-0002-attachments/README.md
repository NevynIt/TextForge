# ADR-0002 Attachments

Package refactor reports for `ADR-0002 - Package root modularization` are stored here.

Each package report must include:

- selected package name;
- files created;
- files modified;
- files removed, if any;
- before/after public export comparison;
- import compatibility notes;
- commands run;
- test/build results;
- remaining risks or manual checks.
